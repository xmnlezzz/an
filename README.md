# Andrómeda 4 — Proyecto final

Landing page estática lista para GitHub Pages. El isotipo SVG está integrado en el propio `index.html`, así que no depende de que se suba una imagen externa.

## Publicación

1. Descomprime este ZIP. Los archivos del sitio (`index.html`, `styles.css`, `script.js`) quedarán directamente en la carpeta extraída.
2. Sube esos archivos a la raíz de tu repositorio de GitHub Pages, junto con la carpeta `assets` (contiene la fuente SVG del isotipo).
3. En GitHub abre **Settings → Pages**. Selecciona **Deploy from a branch**, elige `main` y `/ (root)`, y guarda.
